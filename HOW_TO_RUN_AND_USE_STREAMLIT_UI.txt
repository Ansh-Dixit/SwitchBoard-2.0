2. COMPLETE GUIDE TO ALL TABS & FUNCTIONS IN THE STREAMLIT UI
--------------------------------------------------------------------------------
The Streamlit application (`switchboard/app/streamlit_app.py`) has THREE main tabs:

  [Tab 1] "1. Interactive Demo & Switch-Boundary Inspector"
  [Tab 2] "2. Saved Benchmark Results & Error Analysis"
  [Tab 3] "3. Dataset, Provenance & Annotation Guidelines"

--------------------------------------------------------------------------------
TAB 1: INTERACTIVE DEMO & SWITCH-BOUNDARY INSPECTOR
--------------------------------------------------------------------------------
This tab lets you test individual Hindi–English utterances, play audio, run live
PyTorch transcription with `openai/whisper-small` and PEFT LoRA (+ Auxiliary LID
Head) checkpoints, edit word-level language tags (`HI`, `EN`, `OTHER`), and
inspect word errors at language-switch boundaries (`HI -> EN` and `EN -> HI`).

A. "Step 1: Select Audio Source" (Top-Left Panel)
   You have 4 radio-button options for choosing the input audio:

   1) "Real MUCS 2021 Held-Out Test Utterances (Real Whisper Predictions)"
      - Default mode when the processed MUCS 2021 dataset is present.
      - Utterances marked `✅ [EVALUATED]` at the top of the dropdown have real
        saved predictions from `openai/whisper-small` and the PEFT checkpoints in
        `outputs/full_benchmark_real/`.
      - For any other utterance in the list, click the button
        "⚡ Run Live PyTorch Transcription on Active Audio" to transcribe it live!

   2) "Bundled Hinglish Examples (Ready-to-Try Demo Fixture)"
      - Displays the 5 self-contained classroom demo utterances from `data/demo/`,
        starting with:
        `demo_test_utt_01: "kal meeting ke baad main report submit kar dunga"`
      - Because this mode uses synthetic harmonic audio and scripted pedagogical
        hypotheses by default, the app displays a prominent warning banner:
        `🚨 SIMULATED DATA — NOT REAL MODEL RESULTS`.
      - You can also click "⚡ Run Live PyTorch Transcription on Active Audio" at
        any time to run real `openai/whisper-small` on the active audio file.

   3) "Upload Audio File (.wav, .mp3, .flac)"
      - Upload any `.wav`, `.mp3`, `.flac`, or `.ogg` file (for example, any file
        from `data/processed/audio_16k/mucs2021_hi_en/test/`).
      - SwitchBoard automatically converts stereo to mono, resamples to 16,000 Hz
        16-bit PCM WAV, and runs live `openai/whisper-small` and PEFT checkpoint
        transcription on the uploaded file.

   4) "Record via Microphone"
      - Click the microphone icon in `st.audio_input`, grant browser microphone
        permission, speak a Hindi–English sentence, and click Stop.
      - SwitchBoard resamples your recording to 16 kHz mono WAV and runs live
        `openai/whisper-small` and PEFT checkpoint transcription on it.

B. "Checkpoint & Inference Settings" (Top-Right Panel)
   1) "Fine-Tuned Whisper Checkpoint" Dropdown:
      - `Whisper Small + LoRA + Auxiliary LID Head (checkpoints/whisper_small_lora_plus_lid)`
      - `Whisper Small + LoRA Only (checkpoints/whisper_small_lora_only)`
      - `Full Colab GPU Checkpoint (checkpoints/colab_full_whisper_small_lora_plus_lid)`
      - `Simulate Fine-Tuned Checkpoint Unavailable (Test Missing-Checkpoint Warning)`:
        Displays a clear warning banner when a checkpoint is missing or disabled
        while keeping Baseline Whisper Small transcription 100% operational.
        (Note: The app also automatically blocks any unit-test tiny fallback
        checkpoint from ever being loaded as an ASR model.)

   2) "⚡ Run Live PyTorch Transcription on Active Audio" Button:
      - Executes a live forward pass through `openai/whisper-small` and the
        selected PEFT checkpoint on the currently active audio file and displays
        measured latency (seconds) and Real-Time Factor (`RTF`).

C. "Step 2: Side-by-Side ASR Output Comparison"
   - Left Column: Primary Baseline (`openai/whisper-small`) raw transcript,
     normalized transcript, decoding settings (`task='transcribe'`), latency, and RTF.
   - Right Column: Fine-Tuned (`Whisper Small + PEFT LoRA + Auxiliary LID Head`)
     raw transcript, normalized transcript, latency, and RTF (or clear warning
     if the checkpoint is unavailable).

D. "Step 3: Reference Transcript & Editable Word-Level Language Tags (HI, EN, OTHER)"
   1) Reference Transcript Input Box:
      - Edit or enter the ground-truth reference sentence.
   2) Space-Separated Word-Level Language Tags Input Box:
      - Standard text input containing 1 tag (`HI`, `EN`, or `OTHER`) per word
        (e.g., `"HI EN HI HI HI EN EN HI HI"`). Editing any tag here immediately
        updates the boundary roles, visual badges, and Boundary WER!
   3) "🔧 Click to Edit Individual Word Tags via Dropdown Selectors" Expander:
      - Standard HTML dropdown (`st.selectbox`) for every individual word
        (`#0: kal`, `#1: meeting`, ...), replacing the old canvas-only grid so
        manual tag editing works reliably in all browsers and automation tools.
   4) Switch-Boundary Word Highlighting & Alignment Badges:
      - Highlights every reference word with its language tag (`HI` blue, `EN`
        green, `OTHER` gray) and boundary role (`⚡Pre`, `⚡Post`, or red
        `⚡⇄2x-Switch` for overlapping boundary words counted once).
      - Displays word-level alignment operations (`MATCH`, `SUB`, `DEL`, `INS`,
        `UTT_INS`) and 4 metric cards (`Norm Overall WER`, `Raw Overall WER`,
        `Boundary WER`, `Non-Boundary WER`) plus utterance **CMI**.

--------------------------------------------------------------------------------
TAB 2: SAVED BENCHMARK RESULTS & ERROR ANALYSIS
--------------------------------------------------------------------------------
Strictly separates three distinct result tiers:

  1) "Real Model Benchmark Results (`outputs/full_benchmark_real`) — [REAL MODEL MEASUREMENTS]"
     - Default view. Loads actual neural model evaluation metrics on the held-out
       MUCS 2021 Hindi–English test split.
     - Never allows simulated or demo fixture records.
     - Displays the Model Comparison Table (Raw WER, Norm WER, Norm CER,
       Boundary WER, Non-Boundary WER, `HI->EN` WER, `EN->HI` WER, Pre-Switch WER,
       Post-Switch WER, Mean CMI, RTF, and `Boundary WER Improved?`), skipped/blocked
       checkpoint status, directional/positional breakdowns, CMI range table,
       speaker/accent breakdowns, and per-utterance table.

  2) "Smoke-Test Verification Results (`outputs/smoke_test`) — [SMOKE TEST ONLY]"
     - Displays short pipeline verification outputs.

  3) "Classroom Demo Fixture (`outputs/demo`) — [SIMULATED DATA — NOT REAL MODEL RESULTS]"
     - Displays the 5-utterance synthetic classroom demo fixture under a red
       `SIMULATED DATA — NOT REAL MODEL RESULTS` warning banner.

--------------------------------------------------------------------------------
TAB 3: DATASET, PROVENANCE & ANNOTATION GUIDELINES
--------------------------------------------------------------------------------
  1) Dataset Split Summary & Provenance (`data/full_corpus/unified_manifest.jsonl`):
     - Shows exact utterance counts, disjoint speaker counts, duration in hours,
       and sample canonical manifest records (`original_transcript`,
       `normalized_transcript`, `word_level_language_tags`).
  2) Sample Reviewed Word-Level Annotation Sheet (`docs/sample_annotation_sheet.csv`).
  3) Verified Baseline & Comparison Checkpoints Table (including `requires_ctc_head_training`
     status for `facebook/wav2vec2-xls-r-300m`).
  4) Expandable viewers for `docs/ANNOTATION_GUIDELINES.md` and
     `configs/normalization_equivalents.yaml`.


3. ALL TERMINAL / CLI COMMANDS
--------------------------------------------------------------------------------
Run from `C:\Users\Manas Nigam\Desktop\SwitchBoard`:

  # 1. Run all 23 automated unit & integration tests
  python -m pytest -v

  # 2. Validate the 3,136-utterance real MUCS 2021 manifest
  python -m switchboard.cli validate-manifest --manifest data/full_corpus/unified_manifest.jsonl --check-audio --forbid-demo

  # 3. Verify model checkpoints, local cache status, and CTC head dependencies
  python -m switchboard.cli verify-models

  # 4. Run REAL neural model benchmark evaluation on held-out MUCS 2021 test utterances
  python -m switchboard.cli evaluate-real-benchmark --manifest data/full_corpus/unified_manifest.jsonl --max-utterances 20 --output-dir outputs/full_benchmark_real --run-tier full_research

  # 5. Run Whisper Small PEFT LoRA-only and LoRA+LID curriculum fine-tuning
  python -m switchboard.cli train --config configs/train_smoke_lora_only.yaml
  python -m switchboard.cli train --config configs/train_smoke_lora_lid.yaml

  # 6. Launch the Streamlit application
  python -m streamlit run switchboard/app/streamlit_app.py
